# Branch: feature/tsumkwe-namibia-scenario

This branch covers the scenarios for integrated water, energy, food,
and environment systems (iWEFEs) applicable to the Case Study - Tsumkwe, Namibia

More info on iWEFEs: [OWEFE framework](https://iopscience.iop.org/article/10.1088/2634-4505/acbcee)

v1.0 --> v2.0 --> v3.0

The creation and improvement/development of the following:
- iWEFE minigrid v1.0 (Energy)
- iWEFE minigrid v2.0 (Water and Energy)
- iWEFE minigrid v3.0 (Water, Energy and Food)(conditional)
- Sensitivity Analysis of the iWEFE minigrid configuration
based on MOO(Multiple Objective Optimization) weighting factors
- MOO weighting factors: Cost, Land requirements, GHG emissions, and Water footprints
